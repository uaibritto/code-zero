Code Zero — Curso de JavaScript, TypeScript e Algoritmos do zero ao avançado

Code Zero é uma plataforma gratuita, em português, para aprender a programar do absoluto zero ao avançado: lógica e algoritmos, pensamento computacional, JavaScript, a plataforma web e TypeScript — até construir um projeto real. São 45 módulos organizados em 9 fases, com teoria, exemplos de código, quizzes e exercícios.

Fases do curso

  • Fase 01 — Pensando como programador: do zero absoluto: como máquinas executam código e como pensar em problemas (decomposição, padrões, abstração e algoritmo).
  • Fase 02 — JavaScript básico: valores, variáveis, fluxo e funções — a gramática essencial da linguagem.
  • Fase 03 — JavaScript intermediário: escopo, closures, protótipos, arrays de alta ordem e módulos.
  • Fase 04 — Runtime & internals: o que acontece por baixo dos panos: contexto de execução, event loop, memória e async.
  • Fase 05 — Web Platform: DOM, eventos e as APIs do navegador que dão vida ao JavaScript.
  • Fase 06 — TypeScript fundamental: tipos como extensão do que você já sabe de JavaScript.
  • Fase 07 — TypeScript intermediário: interfaces, unions, narrowing e generics para modelar dados com precisão.
  • Fase 08 — TypeScript avançado: programação em nível de tipos: conditional, mapped e template literal types.
  • Fase 09 — TypeScript aplicado & projeto: levar tudo para o mundo real: APIs, bibliotecas e o projeto final.
