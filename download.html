📦 Projeto completo (.zip)

Todos os arquivos na estrutura de pastas, pronto para subir no GitHub. O .zip é montado aqui no navegador.

📄 Arquivo único (standalone.html)

O curso inteiro embutido em um só arquivo HTML. Funciona offline, sem servidor. Também serve como index.html para deploy em um arquivo só.

🚀 Publicar no GitHub Pages

  1. Suba os arquivos do .zip em um repositório, no branch main.
  2. No repositório: Settings → Pages.
  3. Source: escolha Deploy from a branch → main / / (root).
  4. Em ~1 min o site fica em https://SEU-USUARIO.github.io/SEU-REPO/.

O .zip já inclui .nojekyll e um workflow em .github/workflows/deploy.yml (deploy automático via GitHub Actions, se preferir Source: GitHub Actions).

Se o download não iniciar (alguns navegadores bloqueiam downloads automáticos nesta visualização), abra o standalone.html e use Arquivo → Salvar como… (Cmd/Ctrl+S).
